# ROVIQ brand

Vector versions of the ROVIQ logo, from the brand sheet. Colours: Midnight Navy `#101D2C`, Burnished Copper `#E46F35`, Porcelain `#F4F2ED`, Slate `#647386`.

| File | Use |
|---|---|
| `roviq-lockup.svg` | RR mark + ROVIQ wordmark, on light backgrounds |
| `roviq-lockup-dark.svg` | The same, on dark backgrounds (every app header) |
| `roviq-mark.svg` / `roviq-mark-dark.svg` | RR mark alone |
| `favicon.svg` | App icon: the mark on a navy tile (browser tabs, home screens) |

`scripts/sync-theme.sh` copies these into each app.
